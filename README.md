#   CodeMentor IA

CodeMentor IA es un chatbot de programación desarrollado con FastAPI y Groq. Permite enviar preguntas, obtener respuestas generadas por IA y almacenar el historial de conversaciones en PostgreSQL.

## Tecnologías

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Groq API
- HTML
- CSS
- JavaScript
- Jinja2

## Características

- Arquitectura por capas.
- Persistencia de conversaciones.
- Persistencia de mensajes.
- Integración con Groq.
- Interfaz web propia.
- Base de datos PostgreSQL.

## Instalación

```bash
git clone <url-del-repositorio>
cd CodeMentorIA
python -m venv .venv
source .venv/bin/activate   # Linux/Mac
.venv\Scripts\activate      # Windows

pip install -r requirements.txt
